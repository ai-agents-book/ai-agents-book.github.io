What this site does not do

This is a static page about a book. It sets no cookies, contains no analytics, no tracking pixels, no advertising, no social media buttons and no embedded content. It loads no web fonts and no files from third-party servers, so visiting it causes your browser to contact no one but the host named below. There is no contact form and no newsletter; nothing on this page asks you for personal data.

Hosting and server log files

The site is hosted on GitHub Pages. GitHub documents that when a GitHub Pages site is visited, the visitor's IP address is logged and stored for security purposes, whether or not the visitor is signed in to GitHub (What is GitHub Pages?). GitHub's general privacy statement additionally describes the automatic collection of service and website usage information, including device and request details, the date and time of a visit, and the pages viewed.

Recipient: GitHub, Inc., 88 Colin P. Kelly Jr. Street, San Francisco, CA 94107, USA, as the provider of the GitHub Pages hosting service.

Legal basis: Article 6(1)(f) GDPR. The legitimate interest is the secure and reliable delivery of the page.

Retention: GitHub determines the retention period for these server log data in accordance with its own privacy policies. We have no access to these logs, do not evaluate them, and cannot independently delete them.

Transfer to a third country: GitHub stores and processes personal data in several locations, including the United States. GitHub states that it has certified adherence to the EU–U.S. Data Privacy Framework Principles, and that for transfers to countries without an adequacy decision it relies on the standard contractual clauses published by the European Commission. Both are described in the GitHub General Privacy Statement.

Colour scheme setting

The page offers a light and a dark appearance. It follows your operating system's setting unless you press the button that switches it. If you do, that choice — the single word light or dark — is stored in your browser's local storage so the page still looks the way you left it next time.

This is not a cookie, is never transmitted anywhere, contains nothing about you, and is not used to recognise you. It is stored only because you asked for it by pressing the button, which is why no consent banner appears (§ 25(2) TDDDG). Clearing your browser's site data removes it; if you never press the button, nothing is stored at all.

Links to other sites

This page links to external sites, including GitHub and the personal and university pages of the authors. Following a link takes you to a provider with its own privacy practices, over which we have no influence. Nothing is transmitted to them until you click.
